# 암행어사(Inspector) 감찰 체크리스트

이 체크리스트는 프로젝트의 아키텍처, 코드 위생 및 문서 상태에 대한 암행어사 감찰을 실천할 때 사용합니다.

- [ ] **프로젝트 전수 스캔**: `GEMINI.md`, `PROJECT_TASKS.md`, `_context.md`, `DECISION_LOG.md` 파일이 존재하고 불일치가 없는지 확인했는가?
- [ ] **아키텍처/컨텍스트 정렬**: 설계와 구현 간의 구조적 모순, 혹은 요구사항 명세(PRD) 대비 구현 누락이 없는지 확인했는가?
- [ ] **에러 처리 및 엣지케이스**: 네트워크 오프라인, 인증 만료, DB 예외 등 주요 실패 복구 로직이 감찰되었는가?
- [ ] **보안 및 환경변수 감사**: API 키 하드코딩 여부와 개인 파일 유출 위생 상태를 직접 파일 내용을 검토하여 검증했는가?
- [ ] **문서 및 결정 기록 매칭**: 의사결정 로그(`DECISION_LOG.md`)에 등재된 결정 사항이 실제 코드에 일관성 있게 구현되었는지 감사했는가?
- [ ] **감찰 보고서 저장**: 감찰 결과를 `_audit_YYYY-MM-DD.md` 형태로 프로젝트 루트에 작성하고 이전 보고서를 아카이빙했는가?
