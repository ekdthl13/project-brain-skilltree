# 인스타엔진 CHECKLIST

> 인스타엔진 산출물 검수표다.
> 긴 예시는 `REFERENCES.md`, 실행 절차는 `SKILL.md`를 따른다.

## Hard Fail

- [ ] 시공 결과물 또는 제품 디테일을 AI 이미지로 대체하지 않았다.
- [ ] `shortform_package.md` 같은 통합 1파일로 뭉치지 않고, 모드별 분리 파일 구조로 저장했다.
- [ ] DM 자동 응답, API 업로드, 광고 API 집행을 지시하지 않았다.
- [ ] 브랜드 고유 정보는 프로젝트 `AGENTS.md` 또는 브랜드 문서에서 확인했다.
- [ ] CTA가 콘텐츠 목적 태그와 충돌하지 않는다.

## 공통 검수

- [ ] 목적 태그가 명시되어 있다.
- [ ] 포맷이 명시되어 있다.
- [ ] 원천 자료가 명시되어 있다.
- [ ] CTA가 있다.
- [ ] 캡션과 해시태그가 있다.
- [ ] 성과 입력 기준이 있다.
