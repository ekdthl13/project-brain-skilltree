# 출시점검(Launch Check) 배포 전 체크리스트

이 체크리스트는 프로덕션 환경에 서비스를 릴리즈하기 직전에 시스템 안정성과 위생 상태를 보장하기 위해 사용합니다.

- [ ] **빌드 및 린트 검증**: `npm run build` 및 `npm run lint`가 경고나 에러 없이 성공적으로 수행되는가?
- [ ] **타입 안정성**: TypeScript 프로젝트의 경우 `npx tsc --noEmit`가 에러 없이 완료되는가?
- [ ] **환경변수 위생 검사**: `.env` 파일이 Git 추적 리포지토리에 커밋되지 않았고, `.gitignore`에 제대로 명시되었는가?
- [ ] **비밀키 노출 여부**: 소스 코드 내에 하드코딩된 OpenAI API Key, GitHub Token 등 민감한 자격 증명이 없는가?
- [ ] **코드 클린업**: 디버깅용 `console.log` 및 미사용 import 등 불필요한 코드 블록이 정리되었는가?
- [ ] **기본 SEO 정보 설정**: 각 페이지마다 고유한 `<title>` 태그와 메타 설명(`<meta name="description">`)이 설정되었는가?
- [ ] **웹 접근성 자율 체크**: 텍스트와 배경의 대비율이 가독하기 적절한지 시각적으로 검증했는가?
- [ ] **런타임 스모크 테스트**: 로컬 dev 서버를 기동하여 메인 경로(/) 및 주요 동적 경로가 200 OK를 반환하는지 브라우저 도구로 확인했는가?
- [ ] **출시 보고서 작성**: 점검 결과를 `_launch_check.md` 형태로 프로젝트 루트에 덮어쓰기 방식으로 저장했는가?
