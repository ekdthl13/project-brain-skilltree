# 블로그엔진 CHECKLIST

> 블로그엔진 최종 검수표다. 실행 흐름은 `SKILL.md`, 상세 규칙은 `REFERENCES.md`, 글 유형별 구조는 `TEMPLATES.md`를 따른다.

## Hard Fail

- [ ] 검색 의도 분석 없이 본문부터 쓰지 않았다.
- [ ] 제목 후보 5개 없이 추천 제목만 내지 않았다.
- [ ] 금지 도입부(`안녕하세요`, `오늘은 ~ 알아보겠습니다`)를 쓰지 않았다.
- [ ] AI 냄새 금지 표현을 반복하지 않았다.
- [ ] 근거 없는 통계나 일반론을 만들지 않았다.
- [ ] CTA가 광고처럼 과하게 보이지 않는다.
- [ ] 품질 채점 없이 완료 처리하지 않았다.
- [ ] 프로젝트 브랜드/톤 문서가 있으면 먼저 반영했다.

## Input Check

- [ ] 주제/키워드를 확인했다.
- [ ] 플랫폼을 확인하거나 네이버 블로그 기본값을 적용했다.
- [ ] 타겟 독자와 목표 행동을 추론 또는 확인했다.
- [ ] `BRAND_CONTEXT.md`, `CONTENT_PLAN.md`, `POSTING_REGISTRY.md`가 있으면 참조했다.
- [ ] 글 유형 또는 템플릿(A~F/S)을 선택했다.

## Output Check

- [ ] 제목 후보 5개와 추천 제목 1개가 있다.
- [ ] 검색자 유형, 검색 단계, 독자 감정, Pain Point가 있다.
- [ ] 썸네일 카피 3개가 있다.
- [ ] 본문은 도입, 정보 블록, 사례, 요약, CTA 흐름을 가진다.
- [ ] 표/리스트가 최소 1개 있다.
- [ ] 체류 인터럽트가 최소 2회 있다.
- [ ] 실제 사례, 수치, 현장 변수, 고객 질문 중 3개 이상이 있다.
- [ ] 내부링크 위치 또는 후보가 있다.
- [ ] 해시태그 5~10개가 태그란 입력용으로 분리되어 있다.

## Quality Score

- [ ] 제목: 15점 기준으로 채점했다.
- [ ] 도입부: 15점 기준으로 채점했다.
- [ ] 본문 구조: 25점 기준으로 채점했다.
- [ ] 경험 밀도: 20점 기준으로 채점했다.
- [ ] SEO: 15점 기준으로 채점했다.
- [ ] CTA: 10점 기준으로 채점했다.
- [ ] 총점 85점 미만이면 수정 후 재채점했다.

## Mode Check

- [ ] `FULL`: 전체 본문과 품질 채점까지 출력했다.
- [ ] `TITLE`: 제목 후보 5개, 추천 제목, 추천 이유만 출력했다.
- [ ] `STRUCTURE`: 검색 의도, 글 구조, 소제목, CTA 위치를 출력했다.
- [ ] `REWRITE`: 기존 글의 문제점, 개선 방향, 수정 본문, 품질 채점을 출력했다.
- [ ] `SERIES`: 시리즈 번호, 클리프행어, 다음 편 CTA를 포함했다.
