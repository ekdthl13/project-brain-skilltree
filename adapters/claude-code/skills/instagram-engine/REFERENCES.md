# 인스타엔진 REFERENCES

> 예시, 템플릿, 샘플 문구를 보관하는 파일이다.
> 실행 규칙은 `SKILL.md`, 검수 기준은 `CHECKLIST.md`에 둔다.

## 목적 태그 예시

| 목적 태그 | 사용 상황 | 대표 포맷 |
|-----------|-----------|-----------|
| SAVE | 나중에 다시 봐야 하는 체크리스트, 비교표, 비용 판단 기준 | 캐러셀 |
| SHARE | 지인에게 보내기 좋은 공감 상황, 실수 방지, 이사/인테리어 팁 | 숏폼/캐러셀 |
| TRUST | 실제 현장, 상담 과정, 전문성, 브랜드 신뢰 강화 | 숏폼 |
| LEAD | 무료 실측, 예약, DM 문의로 이어지는 콘텐츠 | 숏폼/캐러셀 |
| AD | 광고 테스트용 훅, CTA, 타겟별 소구점 검증 | 광고 변형 |

## 실험 로그 예시

```markdown
| 주차 | 가설 | 실행 콘텐츠 | 비교 기준 | 결과 | 해석 | 다음 액션 |
|------|------|-------------|-----------|------|------|-----------|
| 2026-W20 | 정보성 캐러셀 훅을 숫자형으로 밀면 저장수가 오른다 | IG-202605-001~003 | 이전 2주 평균 | 저장수 상승 / DM 없음 | 저장 의도는 강하지만 리드 전환은 약함 | 마지막 장 CTA를 DM 유도형으로 수정 |
```
