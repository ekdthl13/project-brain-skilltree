# 코딩가이드 CHECKLIST

> 코딩가이드 최종 검수표다. 실행 흐름은 `SKILL.md`, 상세 양식과 예시는 `REFERENCES.md`를 따른다.

## 시작 전

- [ ] `AGENTS.md`가 있으면 읽고 우선순위를 반영했다.
- [ ] `_order.md`의 목표, 대상 파일, 금지 영역, 완료 기준을 확인했다.
- [ ] 주변 파일과 기존 패턴을 직접 읽었다.
- [ ] 오더가 모호하거나 위험하면 추측 실행하지 않고 에스컬레이션했다.

## 구현 중

- [ ] 지시 범위 밖 리팩터링을 하지 않았다.
- [ ] 생성물 또는 금지 영역을 직접 수정하지 않았다.
- [ ] 기존 네이밍, 구조, 스타일, 검증 패턴을 따랐다.
- [ ] 필요한 경우 타입/로직/UI/통합 순서로 점진 구현했다.
- [ ] `DESIGN_SYSTEM.md`가 있으면 토큰을 사용했다.

## 검증

- [ ] 오더가 지정한 검증을 실행했다.
- [ ] 프로젝트 표준 검증 또는 변경 범위에 맞는 최소 검증을 실행했다.
- [ ] 검증할 수 없는 항목은 이유를 기록했다.
- [ ] 금지 출력 패턴(`TODO`, `...`, "나머지 생략")이 없다.
- [ ] 불필요한 `console.log`, 주석 처리 코드, 빈 catch가 없다.

## 보고

- [ ] 상태를 `✅ 완료 / ⚠️ 부분 완료 / 🟡 반려 / 🔴 불가` 중 하나로 명시했다.
- [ ] 수정 파일과 변경 요약을 남겼다.
- [ ] 검증 명령과 결과를 남겼다.
- [ ] 남은 이슈 또는 후속 총괄 판단 필요 여부를 남겼다.
- [ ] `_order.md`의 작업 결과 섹션을 작성했다.
