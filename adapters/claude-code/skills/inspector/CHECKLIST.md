# 암행어사 CHECKLIST

> 암행어사 최종 검수표다. 모드 라우터와 Hard Fail은 `SKILL.md`, 상세 템플릿은 `REFERENCES.md`를 따른다.

## 시작 전

- [ ] 사용자 요청과 파일 상태로 Mode A/B/C/D를 직접 선택했다.
- [ ] 대상과 스캔 범위를 명확히 했다.
- [ ] 모드별 상세 절차가 필요하면 `REFERENCES.md`를 확인했다.

## 감찰 중

- [ ] 실제 파일, 코드, 문서, 또는 입력 텍스트를 직접 읽었다.
- [ ] 추측이나 기억만으로 판정하지 않았다.
- [ ] 각 발견 항목에 근거를 붙였다.
- [ ] 심각도(심각/경고/참고/위생)를 매겼다.
- [ ] 해결 방향을 한 줄로 제시했다.
- [ ] 감찰 중 직접 수정하지 않았다.

## 모드별 확인

- [ ] Mode A: 모순, 누락, 과잉, 취약점, 확장성, 사용자 경험, 방향성을 검토했다.
- [ ] Mode B: 7대 아이디어 공격 질문과 반론 가능성을 함께 적었다.
- [ ] Mode C: 기대 기준, 현실 대조, 성숙도 레벨, 빠진 것, 돌파 과제를 구분했다.
- [ ] Mode D: Canonical, Router, Version, Trigger, Output, Conflict, Reference, Size, Adapter를 검토했다.

## 보고

- [ ] 보고서가 심각도별로 정리되어 있다.
- [ ] 위생 점검 리스트 또는 누락 사유가 있다.
- [ ] 저장 경로를 명시했다.
- [ ] Mode A/B/C는 `_audit_YYYY-MM-DD.md` 형식으로 저장했다.
- [ ] Mode D는 `_skilltree_audit_YYYY-MM-DD.md` 형식으로 저장했다.
- [ ] 다음에 연결할 총괄 판단 또는 스킬을 제안했다.
