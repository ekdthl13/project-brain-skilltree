# Agent Instructions and Conventions

## Coding Conventions
- **Language**: TypeScript / Node.js
- **Style**: Functional programming preferred, clean code patterns.
- **Linting**: Keep code standard-compliant.

## Agent Guidelines
1. **Verification**: Run `npm run test` or local validation commands before finishing.
2. **Path Safety**: Never output absolute local paths to configuration or log files.
3. **Escalation**: If requirements are contradictory, ask for clarification via the status reports.
