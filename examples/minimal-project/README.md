# Minimal Project Example

This directory demonstrates the minimal set of files required to run the Project Brain Skilltree operating model inside a local project repository.

## File Structure

- [GEMINI.md](GEMINI.md): Project identity card and constitution. Read by Antigravity at the start of a session.
- [AGENTS.md](AGENTS.md): Specific rules and conventions that all LLM/agent assistants (Codex, Claude, etc.) must follow when editing code in this repository.
- [_context.md](_context.md): The active context file (durable file memory) showing the current state, milestones, and status. Typically kept under 30 lines.
- [_order.md](_order.md): The current task instruction work order generated by the Project Manager (`총괄매니저`) for execution by the coding agent.
- [DECISION_LOG.md](DECISION_LOG.md): The long-term decision register tracking design choices, patterns, and document overrides.
- [PROJECT_TASKS.md](PROJECT_TASKS.md): The active project task list and roadmap progress (approximate %).

## Workflow

1. **Restore Context**: The agent reads `_context.md`, `GEMINI.md`/`AGENTS.md`, and `PROJECT_TASKS.md` to understand the current state.
2. **Execute Order**: The agent executes the active instructions detailed in `_order.md`.
3. **Verify and Update**: Once completed, the agent updates the status in `PROJECT_TASKS.md`, documents decisions in `DECISION_LOG.md` if any, and updates `_context.md` for the next session.
