# PRD 생성 품질 검증 체크리스트

이 체크리스트는 PRD가 고품질로 생성되었는지 에이전트 및 사용자가 검증할 때 사용합니다.

- [ ] **적응형 인터뷰 진행 완료**: 사용자의 첫 대답만으로 작성하지 않고 최소 3라운드 이상의 세부 질의응답을 수행했는가?
- [ ] **비즈니스 목적 명확화**: JTBD(Jobs-to-be-Done)의 세 가지 차원(기능적, 감정적, 사회적 과업)이 정의되었는가?
- [ ] **기계 검증 가능한 인수 조건**: Given-When-Then 양식 또는 정량적인 수치로 인수 조건이 서술되었는가?
- [ ] **범위 제한 (Out-of-Scope) 기재**: 스코프 크립을 막기 위한 명시적 금지 기능이 최소 3개 이상 기재되었는가?
- [ ] **Mermaid 다이어그램 포함**: 유저 플로우(상태 다이어그램) 및 데이터 ERD가 Mermaid 문법으로 표현되었는가?
- [ ] **AI Evals 검증 관문**: 개발 에이전트가 코드를 완성한 후 자체 테스트할 수 있는 검증 항목(EVAL)이 포함되었는가?
- [ ] **구현 단계 분할**: 각 개발 단계(Phase 0 ~ Phase N)가 명확하고 격리되어 정의되었는가?
