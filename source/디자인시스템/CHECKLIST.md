# 디자인 시스템 품질 검증 체크리스트

이 체크리스트는 디자인 시스템 규칙이 준수되고 컴포넌트가 올바르게 조립되었는지 확인할 때 사용합니다.

- [ ] **디자인 토큰 정의**: 브랜드 컬러, 타이포그래피, 간격(Spacing), 섀도우(Shadow) 규칙이 CSS 변수로 명세화되었는가?
- [ ] **안티-슬롭(Anti-Slop) 수립**: 디자이너의 가이드 없는 주관적 마진/패딩 사용을 명시적으로 금지하고 규격화된 크기만 허용하도록 지시했는가?
- [ ] **다크모드 지원**: 라이트모드와 다크모드 대응을 위한 시멘틱 컬러 매핑 규칙이 포함되었는가?
- [ ] **웹 접근성 (WCAG AA)**: 텍스트와 배경의 대비비가 최소 4.5:1 이상을 만족하는지 확인 기재되었는가?
- [ ] **애니메이션 토큰**: UI 마이크로 인터랙션을 위한 전환 효과 속도와 이징(Easing) 변수가 포함되었는가?
- [ ] **컴포넌트 프리뷰**: 디자인 가이드를 시각적으로 확인할 수 있는 `DESIGN_PREVIEW.html` 파일이 정의되었는가?
